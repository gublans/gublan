Make games in plain words.

Gublan is a small programming language and studio for beginners. Write short, English-like commands, press run, and play what you made, in 2D or 3D, as code or as blocks.

Download for Windows Try it in your browser

Gublan Studio {{VERSION}} · updates itself

Everything you need to make your first game

Gublan Studio is an editor, a game window, a debugger and a set of guides in one app.

Reads like English

Short commands, one per line, and error messages that say what went wrong and how to fix it.

Code or blocks

Edit as text, as blocks, or side by side. Both views are the same program.

2D and 3D games

Shapes, sprites, sound, tweens and particles, with keyboard, mouse, buttons, sliders and text boxes.

Learn as you debug

Breakpoints, step-through, variable watches, hints for every command and a live problem checker.

Bring your code

Convert Python, JavaScript and Lua (even pygame, p5.js and LÖVE games) into Gublan, or export back out.

Code together

Host a live session and edit with friends on your network. Everyone gets their own named cursor.

AI helpers

Connect Claude, Copilot, Cursor or any MCP client to read, run, test and screenshot your project.

Make it yours

Themes, accent colours, cursors, typing effects, sound sets, plugins and your own modules.
